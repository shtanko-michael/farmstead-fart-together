# Fart Together — план разработки

> Идея владельца. Мультяшный юмор с настоящим геймплеем и кооперативом «вместе».

## 1. Концепция и аудитория

Персонажи пускают газы по клавише (или эмоцией): поза с анимацией, облачко частиц и один из 20+ звуков. Газ копится от еды. Облако отпугивает мобов, «реактивный» выхлоп подбрасывает в прыжке, а одновременный залп нескольких игроков рядом даёт усиленный эффект и ачивки.

**Аудитория:** SMP-серверы с друзьями, стримеры и ютуберы, «cursed»/fun-модпаки, дети и семьи — по умолчанию мод без урона.

**Почему зайдёт.** Юмор и «стримерские» моды разлетаются через ролики, а у категории cursed (2,1 на 1000 модов) почти нет качественных работ. Сильная подача (анимация, хорошие звуки, кооп) выделит мод среди однодневных шуток. Главный канал — короткие видео, их мы делаем сами.

## 2. Функции

### MVP

- Клавиша (по умолчанию `G`) → поза: присед, выгнутая спина, руки к коленям; облако зелёных частиц сзади; случайный звук из набора.
- **Шкала газа** (иконка над хотбаром): копится от еды, у каждой еды свой «газовый вес».
- **Свои предметы:**
  - бобы (растение и урожай; «Миска бобов» — мощный заряд);
  - капуста;
  - «Тухлое яйцо».
- **Ванильная еда:** суп из грибов, свёкла, тухлая плоть, зачарованное яблоко — особый «золотой» эффект.

### 1.0

- **Сила залпа — удержанием** (решение владельца 12.11.2026): пока G зажата, сила растёт до того, что есть на шкале газа; отпустили — залп. Короткое нажатие — малый залп (выходит `charge.minToToot`). Нарастание видно на HUD. Сервер решает: клиент шлёт только длительность удержания, сервер режет её своим газом и `toot.fullChargeSeconds`. Ступени: малый, средний, мощный и «легендарный» (полная шкала, удержанная до конца).
- **Облако газа** — сущность на 5–15 с:
  - мобы рядом убегают (как от кота у криперов);
  - жители морщатся;
  - пчёлы злятся;
  - огонь или лава рядом → маленький безопасный хлопок (без разрушения блоков по умолчанию).
- **Реактивный прыжок:** залп в воздухе даёт небольшой подброс и замедляет падение. Кулдаун, расход заряда.
- **Fart Together:** 2+ игрока в радиусе 6 блоков делают залп в окне 1,5 с → комбо-облако, особый звук «хором», подсветка участников, счётчик комбо в чате. Ачивки на 2, 4 и 8 игроков.
- **Эмоции:** «смущение» (краснеет лицо — оверлей на скин), «ой» от ближайших игроков.
- **Звуки:** 20+ вариаций по силе (короткие, длинные, «скрипучие», «пузырьковые» под водой) плюс редкий «музыкальный» залп (1%).
- **Подводный режим:** пузыри вместо облака.
- **Ачивки:** первый залп, легендарный залп, залп у Иссушителя, комбо 8.
- **Режимы урона и PvP (серверный конфиг):**
  - `harmless` — по умолчанию;
  - `nausea` — тошнота в облаке;
  - `toxic` — лёгкий яд, PvP только при включённом PvP.

### После 1.0

- Мобы с газами (свиньи и коровы изредка; отключаемо).
- «Газовый фильтр» — шлем с цветком, иммунитет к облаку.
- Интеграция с Simple Voice Chat — эффект на голос в облаке (шутка, опционально).

### Личный стиль игрока (требование владельца, 12.11.2026)

Каждый игрок настраивает, как выглядит и звучит **его** залп, а друзья рядом **видят и слышат именно это**.

| Группа | Настройки |
| --- | --- |
| Цвет облака | пресеты (болотный, бобовый, сиреневый, золотой, «тыква», «ёлка»…), свободный HEX/RGB, градиент из двух цветов, «случайный», «радуга» (право) |
| Частицы | форма (пух, пузырьки, искры, листья, ноты, сердечки, снежинки), размер, количество, разлёт, время жизни облака, дрейф по ветру |
| Звук | выбор из 24+ звуков или «случайный из набора», высота тона (0,5–2), громкость; мини-наборы («скромник», «труба», «пищалка») |
| Поза | вариант анимации (присед, «балерина», «супергерой», «ничего не было»), тряска |
| Дополнительно | след за реактивным прыжком, искорки, сезонные стили (Хэллоуин, Новый год, 1 апреля) — автоматом по дате или вручную, подпись в чате при комбо, «эмодзи-облачко» над головой |

Правила:

- Стиль хранится в клиентском конфиге (секция `style`), редактируется на экране настроек с живым превью — «Попробовать», как в Footprints, плюс отдельная вкладка «Мой стиль» с крутящейся моделькой и кнопкой «проиграть».
- При входе и при каждом сохранении клиент шлёт стиль серверу (C2S `style`, не чаще раза в 2 с). Сервер **проверяет** его: обрезает размеры и количество до серверных лимитов, отбрасывает неизвестные звуки и формы, снимает опции без права (`…style.rainbow`, `…style.huge`, `…style.sounds.rare`), хранит у игрока (вместе с зарядом) и рассылает всем, кто этого игрока видит (S2C `style` при входе в зону трекинга и при смене).
- Сам залп (S2C `toot`) несёт только id игрока, силу и seed — стиль у получателей уже есть, пакет маленький.
- Серверный конфиг `[style]`: какие опции разрешены, максимум частиц/размера/длительности, «принудительный стиль сервера» для серьёзных серверов.
- Клиентский переключатель `style.others`: `THEIRS` (видеть чужие стили, по умолчанию) / `SIMPLE` (у всех мой простой стиль) / `MINE` (у всех мой стиль). Плюс общий лимит частиц для слабых ПК.
- Игроки без мода ничего не видят — это нормально. Сервер без мода: залп виден только себе (режим «только для себя»).

Это делает сеть обязательной на всех лоадерах — см. §4, «Сеть и зависимости».

## 3. Платформы

- Полная матрица: 1.20.1 Forge и Fabric, 1.21.1 NeoForge и Fabric, 26.x NeoForge и Fabric.
- Сторона: оба. Клиент без серверной части видит только свои анимации и звуки — режим «только для себя» без геймплея.
- Анимацию игрока пишем сами (мини-система ключевых кадров на `HumanoidModel`): playerAnimator не поддерживает 26.x. Если playerAnimator стоит, поза интегрируется с ним, чтобы не конфликтовать с Better Combat и Emotecraft.

## 4. Архитектура

- **`gas`** — шкала заряда (data attachment игрока, синхронизация клиенту), веса еды — data-driven JSON `data/fart_together/gas_foods/*.json`, модовая еда добавляется датапаком.
- **`action`** — C2S-пакет «залп» (сила по удержанию) → сервер валидирует заряд, кулдаун и права → S2C всем в радиусе слышимости: анимация, частицы, звук (seed для одинаковой вариации у всех).
- **`cloud`** — сущность `GasCloudEntity`: радиус, время, режим. Цели AI отпугивания добавляются мобам из тега `fart_together:scared_by_gas`.
- **`together`** — серверный детектор комбо по окну времени и радиусу.
- **`anim`** — клиент: keyframe-анимации из JSON (поза, тряска, «облегчение») поверх модели игрока; совместимость с First-person Model и Not Enough Animations.
- **`items`** — бобы (культура, семена, урожай, миска), капуста, тухлое яйцо (бросаемое, создаёт облако).
- **`advancements`**, **`stats`** («залпов всего», «рекорд комбо»).
- **`style`** — личный стиль игрока: клиентская секция конфига, C2S при входе/сохранении, серверная проверка и лимиты, хранение у игрока, S2C всем, кто его трекает (см. §2).

### Сеть и зависимости (решение 12.11.2026)

**Решение: на Fabric мод требует Fabric API. На NeoForge и Forge — ноль зависимостей** (всё нужное есть в самом лоадере). Footprints обходится без Fabric API, потому что он чисто клиентский и рисует сам. Fart Together — нет.

Пакеты нужны в обе стороны на всех 22 целях: C2S «залп» и «мой стиль», S2C «залп игрока N», «стиль игрока N», «заряд». Без Fabric API это возможно, но дорого:

| Что нужно | Без Fabric API | С Fabric API / в лоадере |
| --- | --- | --- |
| Свои пакеты | 1.20.1: миксины в `handleCustomPayload` обеих сторон (легко). 1.20.5+: неизвестный payload ваниль превращает в `DiscardedPayload` и **выбрасывает байты** — нужен миксин в выбор кодека `ServerboundCustomPayloadPacket`/`ClientboundCustomPayloadPacket` и в конфигурационную фазу; эти места менялись в 1.20.5, 1.21.2, 1.21.5, 1.21.9, 26.1 | `ServerPlayNetworking`/`PayloadTypeRegistry` (Fabric), `RegisterPayloadHandlersEvent` (NeoForge 1.20.5+), `SimpleChannel` (Forge 1.20.1) |
| Текстуры, модели, `sounds.json`, звуки `.ogg` мода | Ваниль не видит ресурсы модов: свой источник пакетов через миксин в `PackRepository`/`ClientPackSource` (Footprints читает так только lang) | `fabric-resource-loader-v0` |
| Регистрация бобов, капусты, яйца, блока-грядки, сущности облака, звуков, частиц | `Registry.register` работает, но нет проверки совпадения id между клиентом и сервером: разные наборы модов = тихо перепутанные предметы | `fabric-registry-sync` (проверяет и пересопоставляет) |
| Вкладка творчества, сделки жителей, лут, рендер сущности, HUD, клавиша | по миксину/accessor на каждое, на каждый диапазон версий | модули Fabric API |
| Данные игрока (заряд, стиль) | свой NBT через миксин в `Player` save/load | attachments (1.20.5+), на 1.20.1 — свой NBT |

Итого без Fabric API — 10–15 версионно-зависимых миксинов на сетевой и ресурсный слой, которые ломаются с каждой версией MC, и без защиты от рассинхрона реестров. Fabric API стоит почти у всех игроков Fabric (самый скачиваемый мод Modrinth) и есть под все наши цели (12.11.2026: 0.92.12+1.20.1, 0.116.18+1.21.1, 0.114.1+1.21.3, 0.119.4+1.21.4, 0.128.2+1.21.5, 0.136.1+1.21.8, 0.138.4+1.21.10, 0.141.6+1.21.11, 0.155.3+26.1.2, 0.161.0+26.2, 0.166.2+26.3). Конкуренты на Fabric тоже его требуют. Цена — одна строка «требует Fabric API» в описании.

Как устроено в коде:

- `net/` — общий слой: записи пакетов (`TootC2S`, `StyleC2S`, `TootS2C`, `StyleS2C`, `ChargeS2C`) с ручной сериализацией в `FriendlyByteBuf` (одна реализация на все версии), интерфейс `Network` с `toServer()`, `toTracking(player)`, `toPlayer()`.
- `platform/<loader>/…Network` — тонкие обёртки: Fabric API networking, NeoForge payload-события, Forge `SimpleChannel`. Версионные различия (`CustomPacketPayload` с 1.20.5, `StreamCodec`) — Stonecutter-комментариями только в обёртках.
- Протокол с версией: при входе сервер шлёт `hello(version, limits)`; клиент без мода или со старой версией — режим «только для себя», без крашей и кика. Сервер без мода — то же.
- Анти-спам на сервере: залп не чаще кулдауна, стиль не чаще раза в 2 с, размер пакета стиля ≤ 512 байт.
- Футпринтовский каркас (свои миксины на тик, клиентскую команду и lang) остаётся до перехода на Fabric API в M1, потом заменяется событиями Fabric API.

Владелец может отменить решение: тогда M1 начинается с миксинного слоя пакетов и ресурсов, а оценка M1–M4 растёт примерно на неделю, плюс поддержка на каждую новую версию MC.
